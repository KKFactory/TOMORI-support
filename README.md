# TOMORI サポート

**毎日に、小さな灯りを。** TOMORIは、予定・時計・天気・歩数をまとめて表示するiPad向けダッシュボードです。

## お問い合わせ

[お問い合わせ・不具合報告を作成する](https://github.com/KKFactory/TOMORI-support/issues/new/choose)

使い方の質問、不具合、ご要望は、このリポジトリのIssuesへお寄せください。投稿にはGitHubアカウントが必要です。日本語・英語で受け付けます。

**投稿内容は公開されます。** 予定の内容、健康情報、自宅の住所・座標、メールアドレス、購入情報などは記載しないでください。画面を添付する場合は個人情報を隠してください。

不具合の報告には、アプリのバージョン、iPadOSのバージョン、iPadの機種、再現手順があると確認しやすくなります。

## 天気について

天気データは [MET Norway](https://www.met.no/) 提供、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) に基づき利用します。TOMORIで時間別予報を集計し、日本語表記に加工しています。

天気を使うと設定した座標と通信元IPアドレスがMET Norwayへ伝わります。GPSで現在地を取得する機能はありません。詳しくはアプリ内の「プライバシーとデータの取り扱い」をご覧ください。
